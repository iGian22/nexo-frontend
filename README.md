# Nexo — TP Final Frontend

Nexo es una aplicación web desarrollada con React que permite crear y administrar círculos, explorar comunidades y mantener conversaciones mediante salas de chat.

La aplicación fue desarrollada como Trabajo Práctico Final de Frontend, aplicando React, React Router, Context API, estados, componentes reutilizables y diseño responsive.

## Tecnologías utilizadas

- React
- Vite
- React Router DOM
- Context API
- Lucide React
- CSS3
- LocalStorage

---

## Funcionalidades

- Crear círculos.
- Explorar círculos.
- Navegación entre páginas mediante React Router.
- Conversaciones por salas.
- Envío de mensajes.
- Perfil editable.
- Sistema de favoritos.
- Persistencia de datos utilizando LocalStorage.
- Búsqueda mediante parámetros de URL (`useSearchParams`).
- Diseño responsive desde 320px hasta pantallas de escritorio.

## Dificultades encontradas

Durante el desarrollo uno de los principales desafíos fue organizar el estado global mediante Context API y mantener la persistencia de la información utilizando LocalStorage.

También se trabajó en lograr una interfaz responsive para distintos tamaños de pantalla sin duplicar componentes y manteniendo una estructura de código simple y reutilizable.
